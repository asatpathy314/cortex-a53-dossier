# Cortex-A53 source dossier

A reading guide to the Arm Cortex-A53: manuals, books, research, and measurements. Start at [index.md](index.md) or browse the [source guide](DOSSIER.md).

[Published website](https://asatpathy314.github.io/cortex-a53-dossier/).

## Local preview

With Ruby and Bundler installed (on this Mac, use the Homebrew Ruby path below):

```sh
export PATH="/opt/homebrew/opt/ruby/bin:$PATH"
bundle install
bundle exec jekyll serve --host 127.0.0.1 --port 4000
```

Open <http://127.0.0.1:4000/cortex-a53-dossier/>. Jekyll rebuilds when you save content changes; refresh the browser to see them.
